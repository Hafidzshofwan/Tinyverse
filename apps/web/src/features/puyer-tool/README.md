# feature: puyer-tool (Racik Puyer)

Island loader untuk Racik Puyer, port verbatim dari TinyVerse v17 (halaman
`page-puyer`). Skrip v17 berupa IIFE mandiri yang membaca `daftarObat`.

## Dataset obat offline
Sama seperti Dosis Obat, dataset bawaan `obat.json` disuntikkan ke
`/puyer-tool.html` agar preset, pencarian, rentang dosis, dan cek interaksi
berjalan offline dan SAMA PERSIS dengan v17.
